Only the distance between loci matters, never the absolute value. Mark anything you can see down the scope as fluorescent — Cross Bench then works out how many F2 you actually have to pick and genotype, as opposed to merely look at.

4 · F2 outcome

    Assumptions, and how bp positions are converted

    The cross. Male × hermaphrodite, F1 cross-progeny hermaphrodites selfed, F2 scored. Autosomal alleles come half from each parent; on X, an F1 cross-progeny hermaphrodite gets the father's single X plus one maternal X. F1 males (which inherit no paternal X) are ignored, since you're selfing F1 hermaphrodites.

    Crossing over. The default model is complete interference: exactly one crossover per bivalent per meiosis, giving each chromosome a 50 cM genetic length, so a crossover in one interval excludes a crossover in any other. Under this model the recombination fraction between two loci is simply d/100 and never needs a Haldane correction. The Haldane option is there for comparison; it will overestimate double crossovers in worms.

    Screening on a marker. A locus marked fluorescent is used to pre-sort F2 at the dissecting scope. The criterion is derived from what you asked for, so it is always a necessary condition for the target and can never throw away a worm you wanted: if you want the allele, you keep the glowing worms; if you want it gone, you keep the dark ones. "Glows if carried" treats homozygotes and heterozygotes as indistinguishable, which is the honest default for most single-copy knock-ins; "hom brighter than het" assumes you can call copy number by eye, which is realistic for bright arrays and integrated multi-copy lines but not for every knock-in.

    What is not modelled. Balancers are treated only as ordinary loci — set the interval distance to 0 cM to represent suppressed recombination, and tick hom. lethal for a lethal balancer. Male mating efficiency, brood size, self-progeny contamination on the cross plate, dominance, penetrance, maternal effect and any selection acting on F2 classes are all outside the calculation.

    bp → cM. Worm chromosomes have non-recombining tips, high-recombination arms and a low-recombination central cluster, so base pairs are a poor proxy for map distance. The converter below uses a per-chromosome three-domain approximation: non-recombining tips, a central cluster taking a set share of the 50 cM, and arms sharing the rest in proportion to their physical length. It is an estimate for planning, not a lookup — where the answer matters, take the genetic position from the gene's WormBase page and enter cM directly.
